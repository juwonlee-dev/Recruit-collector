    내 위젯

    위젯은 이력서의 항목 하나입니다. 입력 칸마다 힌트(입력 칸에 흐리게 보이는 안내)와 예시 텍스트(이력서를 만들 때 미리 채워지는 내용)를 정할 수 있고, 여러 템플릿에서 조합해 씁니다. 템플릿에 넣은 위젯은 그때의 내용이 복사되므로, 여기서 고쳐도 이미 만든 템플릿은 바뀌지 않습니다.

    처음이라면: 위젯 만드는 순서
    1. 종류를 고르고 '새 위젯'을 누릅니다. 입력 항목은 이력서에 적을 칸(경력, 자격증 등), 제목·고정문구·구분선은 문서에 그대로 찍히는 장식입니다. 비슷한 위젯이 있으면 '복사해서 편집'이 빠릅니다.
    2. 입력 항목이면 제목, 반복 여부(경력처럼 여러 개), 문서 표시 형식을 정합니다.
    3. 입력 칸을 추가하고 종류(글·날짜·전화번호 등)·너비·힌트·예시 텍스트를 정합니다.
    4. 저장한 뒤 템플릿 편집 화면의 위젯 목록에서 넣어 씁니다. 넣을 때 내용이 복사되므로, 나중에 위젯을 고쳐도 이미 넣은 템플릿은 그대로입니다.
